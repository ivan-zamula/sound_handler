# Анализ нот и тональности (2022)

[English](README.md) | [Русский](README.ru.md)

Эксперименты с анализом звукового сигнала на Python с помощью быстрого преобразования Фурье (БПФ). Код находит основные частоты и музыкальные ноты, а также оценивает тональность аудиосигнала.

## Методы и инструменты

- Графики звуковой волны и спектра.
- БПФ, оконные функции и оценка спектральной плотности мощности методом Уэлча.
- Поиск пиков спектра и преобразование частот в ноты.
- Оценка тональности по хроматическим признакам и корреляции с профилями мажора и минора.

Используются librosa, NumPy, SciPy, Matplotlib и PeakUtils. Версии зависимостей указаны в [requirements.txt](requirements.txt).
